# کامپوننت‌های مشترک اختصاصی

کامپوننت‌هایی که برای دوراتو ساخته یا از ترکیب کامپوننت‌های پایه ایجاد می‌شوند و در چند قابلیت قابل استفاده‌اند، اینجا قرار می‌گیرند.

| فایل                 | کاربرد                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------ |
| `page-loading.tsx`   | بارگذاری صفحه با متن فارسی و Spinner                                                       |
| `theme-toggle.tsx`   | تغییر تم روشن و تاریک                                                                      |
| `loading-button.tsx` | دکمه عملیات با loading، جلوگیری از کلیک مجدد و `aria-busy`                                 |
| `text-field.tsx`     | Input همراه label، توضیح و خطای متصل به همان کنترل؛ سازگار با ref مربوط به React Hook Form |
| `password-field.tsx` | فیلد رمز با نمایش/پنهان‌سازی و جهت LTR                                                     |
| `empty-state.tsx`    | نمایش وضعیت خالی با عنوان، توضیح، آیکون و action اختیاری                                   |
| `error-state.tsx`    | نمایش خطای API و تلاش دوباره با پیام کنترل‌شده                                             |

برای پیش‌نمایش دستی، در dev به `/dev/components` بروید. این مسیر در build تولید وجود ندارد.

- primitiveهایی مثل Button و Input در `../ui` باقی می‌مانند.
- کامپوننت وابسته به منطق یک قابلیت، مثل فرم ورود یا کارت اکیپ، در `features/<feature>/components` قرار می‌گیرد.
- کامپوننت مشترک داده موردنیازش را با props می‌گیرد؛ این پوشه مستقیماً به featureها import نمی‌دهد.
- فایل‌ها kebab-case و نام کامپوننت‌ها PascalCase باشند؛ لازم نیست نام هر کامپوننت با `Custom` شروع شود.
