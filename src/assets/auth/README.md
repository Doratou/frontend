## بررسی اندازهٔ پس‌زمینهٔ لپ‌تاپ

مرجع این اصلاح، اسکرین‌شات ۱۹۲۰×۹۲۳ ارسالی کاربر و فایل موجود ۱۷۷۴×۸۸۷ است؛ از فریم‌های Figma برای انتخاب اندازه استفاده نشد. حالت‌ها طبق [MDN object-fit](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/object-fit)، [راهنمای نسبت تصویر MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Box_sizing/Aspect_ratios) و [الگوریتم استاندارد CSS Images](https://www.w3.org/TR/css-images-3/#cover-contain) مقایسه شدند:

| حالت    | اندازهٔ نمایشی در قاب ۱۹۲۰×۹۲۳ | نتیجه                                                    |
| ------- | ------------------------------ | -------------------------------------------------------- |
| contain | ۱۸۴۶×۹۲۳                       | حدود ۳۷ پیکسل حاشیه در هر طرف                            |
| fill    | ۱۹۲۰×۹۲۳                       | پرشدن قاب با کشیدگی افقی حدود ۴٪                         |
| cover   | ۱۹۲۰×۹۶۰                       | بدون حاشیه و کشیدگی؛ برش حدود ۱۸٫۵ پیکسل از بالا و پایین |

`cover` از ضریب `max(viewportWidth / imageWidth, viewportHeight / imageHeight)` استفاده می‌کند؛ با resize یا zoom دوباره اندازه می‌گیرد. خروجی ثابت ۱۹۲۰×۹۲۳ فقط یک viewport را هدف می‌گیرد و برای همهٔ لپ‌تاپ‌ها کافی نیست. تغییر به اندازهٔ نمایشی responsive محدود شد؛ فایل اصلی دوباره نمونه‌برداری یا دفرمه نشده است. حداقل برش ممکن برای پرکردن قاب با حفظ نسبت، رفتار استاندارد cover است. این محاسبه از ابعاد اسکرین‌شات است؛ اندازه یا زوم پنجرهٔ Chrome واقعی از آن نتیجه گرفته نمی‌شود.

وزن‌های ۸۰۰ و ۹۰۰ IRANYekan از فونت موجود پروژهٔ مرجع BMS خوانده و به پوشهٔ فونت Dorato اضافه شدند. خانواده همان فونت قبلی است؛ فایل‌های BMS تغییر نکرده‌اند. مجوز موجودِ فونت و تصاویر پروژه باید هنگام انتشار محصول رعایت شود.
