# فایل‌های قابل import

تصاویر، آیکون‌ها و فایل‌های عمومی که در کد import می‌شوند، اینجا قرار می‌گیرند؛ Vite می‌تواند آن‌ها را با نام نسخه‌دار وارد خروجی کند. فایل با مسیر ثابت مثل favicon در `public/` قرار می‌گیرد. فایل مخصوص یک قابلیت در `features/<feature>/assets/` نگهداری می‌شود.

دارایی‌ها و فونت‌های پروژه BMS به این پوشه کپی نشده‌اند؛ هویت بصری دوراتو جداست. فونت فعلی از پکیج Vazirmatn بارگذاری می‌شود.
